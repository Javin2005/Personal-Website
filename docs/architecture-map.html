Where each part actually runs

Vercel

serves files · runs none of your code

npm run build turns your React code into plain HTML, JS and CSS files. Vercel just hands those files (and the black hole video) to each visitor from a CDN. The React code then runs on the visitor's computer.

Render

runs Python 24/7 · free tier 512 MB RAM

Gunicorn starts several copies ("workers") of your FastAPI app. Each worker loads all of Python, FastAPI, SQLAlchemy and the Cloudinary SDK into memory, so more workers means more RAM. This is the only place your code runs on a server.

Supabase · Resend · Cloudinary

other companies' servers

Your backend calls them over the internet using secret keys from .env. The browser never sees those keys. That's the main reason the backend exists.
